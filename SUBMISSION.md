# ShopEase – Submission Details

**Project:** ShopEase – E-Commerce Microservices  
**GitHub repository:** https://github.com/mdyusuf2105-design/shopease-product-service  
**Branch:** `main`

## Services delivered
1. Product Management Microservice – FastAPI product CRUD API.
2. Authentication Microservice – account registration, login, JWT authentication, token verification and password change.
3. User Management Microservice – authenticated user profile and address management.

## Technology stack
Python, FastAPI, Pydantic, SQLAlchemy, MySQL, Alembic, JWT, Docker and Docker Compose.

## Local service ports
- Product Service: 8003
- Authentication Service: 8002
- User Management Service: 8004

## Submission note
The repository contains the source code, service-specific documentation, environment-variable examples and Postman collection templates. The Postman collections are prepared for use but have not been executed as part of this preparation.
